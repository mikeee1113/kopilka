Как хранятся данные

  • Пароль не хранится: в базе лежит только его хеш Argon2, из которого пароль не восстановить.
  • После входа браузер получает случайный ключ сессии в cookie, недоступной скриптам страницы. Сессия действует 7 дней.
  • Записи о расходах видны только вам: сервер проверяет владельца при каждом запросе.
