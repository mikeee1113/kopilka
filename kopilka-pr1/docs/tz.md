# Техническое задание — «Копилка», учёт личных расходов

Вариант 23, группа Г «Учёт и статистика». Практическая работа № 1: статические страницы на HTML и CSS.

## Назначение

Сайт-дневник личных расходов. Пользователь видит траты за месяц, распределённые по категориям,
сравнивает их с лимитами и добавляет новые записи.

## Данные

- **Категория** (12 шт.): название, иконка, описание, месячный лимит, тип (обязательные или нет).
- **Запись расхода** (24 шт. за сентябрь 2026): дата, сумма, категория, название, комментарий.

## Страницы

| Страница | Что на ней | Что может пользователь |
| --- | --- | --- |
| Главная `index.html` | Назначение сайта, сводка за месяц (потрачено, число записей, бюджет, шкала), 6 основных категорий, шаги ведения учёта | Перейти к добавлению записи, к списку, на страницу категории |
| Расходы `expenses.html` | Панель фильтра и сортировки, ссылки на 12 категорий, все 24 записи, итог | Просмотреть все записи, перейти в категорию |
| Категория `category-*.html` | Иконка, описание, потрачено, лимит, число записей, средний чек, тип, шкала лимита, записи категории | Оценить траты по категории, перейти к добавлению записи |
| Добавить запись `add.html` | Форма (сумма, категория, дата, название, комментарий), 5 последних записей, итог за месяц со шкалами | Заполнить форму |
| Контакты `contacts.html` | Адрес, телефон, почта, режим работы, слоган, форма обратной связи | Позвонить, написать письмо, заполнить форму |
| 404 `404.html` | Сообщение об ошибке, ссылки на главную и список | Вернуться на сайт |

Меню в шапке есть на всех страницах и ведёт на главную, расходы, добавление записи и контакты.
Страницы категорий открываются с главной и со страницы расходов; на них есть путь «Главная / Расходы / Категория».

## Требования

- Семантическая разметка, один `h1` на странице, заголовки без пропуска уровней, `alt` у всех изображений.
- UTF-8, `lang="ru"`, мета-тег viewport.
- Один файл `css/style.css` для всех страниц, без атрибута `style`; макет на Flexbox и Grid.
- При ширине 360 px нет горизонтальной прокрутки, текст читается, меню доступно, в том числе с клавиатуры.
- Изображения не выходят за пределы контейнеров; собственный логотип.
